# Touch Grass 🌿

An interactive meadow experiment by Mohamed Nishaz, recreated from a video reference and extended with AI-assisted development.

## Explore the live website

**[Open Touch Grass](https://touch-grass-nishaz.mohamednishazproduct.chatgpt.site)**

The live demo is publicly hosted on Sites. This repository contains its self-contained HTML source.

## Interactions

- Brush the grass with a mouse or touch.
- Watch butterflies react to your hand.
- Touch the tree in the morning to send birds flying.
- Switch to night to meet owls whose eyes follow your pointer.
- Toggle rain, splashes, wet grass, and nature sounds.
- Take a timed breathing break.

## Run locally

Download `index.html` and open it in a modern browser with WebGL 2 support. No installation or external assets are required.
